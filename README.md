# Heart Disease Classification Using Machine Learning

## Overview

This is a machine learning project implemented in a Google Colab notebook that predicts the presence of heart disease in patients using clinical data. The goal is to build a model that can accurately classify whether an individual has heart disease or not.

## Project Description

The project analyzes clinical features such as:
- Age
- Blood Pressure
- Cholesterol
- And other relevant medical indicators

Using these features, machine learning algorithms are trained to classify patients into two categories:
- **Positive**: Patient has heart disease
- **Negative**: Patient does not have heart disease

## Technology Stack

- **Language**: Python
- **Environment**: Google Colab Notebook
- **Libraries**: 
  - scikit-learn (for machine learning models)
  - pandas (for data manipulation)
  - numpy (for numerical computations)
  - matplotlib/seaborn (for data visualization)

## Features

- Data preprocessing and exploration
- Feature engineering and selection
- Model training and evaluation
- Classification metrics and performance analysis
- Visualization of results

## Dataset

The project uses clinical data with features related to heart disease diagnosis. The dataset includes both input features (medical measurements) and a target variable indicating the presence or absence of heart disease.

## Models

Various machine learning models are trained and evaluated, such as:
- Logistic Regression
- Decision Trees
- Random Forest
- Support Vector Machines (SVM)
- K-Nearest Neighbors (KNN)
- Gradient Boosting models

## Usage

1. Open the notebook in Google Colab
2. Mount your Google Drive if needed
3. Load the dataset
4. Run the cells sequentially to:
   - Explore the data
   - Preprocess features
   - Train models
   - Evaluate performance

## Results

The trained model provides:
- Classification accuracy
- Precision, Recall, and F1-Score
- Confusion Matrix visualization
- ROC-AUC curves
