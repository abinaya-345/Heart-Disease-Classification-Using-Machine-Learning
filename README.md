## 📌 **Heart Disease Classification Using Machine Learning**

This is a machine learning project implemented in a **Google Colab notebook** that predicts the presence of heart disease in patients using clinical data (e.g., age, blood pressure, cholesterol, etc.). The goal is to build a model that can accurately classify whether an individual has heart disease or not. ([Makoto Takahara][1])

## 🧪 **Dataset**

The model uses the *UCI Heart Disease Dataset* (Cleveland subset) commonly used in machine learning classification tasks. It contains 303 clinical records with 14 attributes including:

* Age
* Sex
* Chest Pain Type
* Resting Blood Pressure
* Cholesterol
* Fasting Blood Sugar
* Maximum Heart Rate
* Exercise-induced Angina
* ST Depression
* Target (presence/absence of heart disease) ([Makoto Takahara][1])
