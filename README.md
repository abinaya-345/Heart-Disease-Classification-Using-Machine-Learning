# ❤️ Heart Disease Classification Using Machine Learning

## 📖 Description
This project focuses on classifying heart disease using various machine learning algorithms. We analyze the dataset, implement different models, and evaluate their performance to find the best approach for heart disease prediction.

## ✨ Features
- Multiple machine learning algorithms
- Comprehensive data analysis
- Visualization of results
- User-friendly interface

## 📥 Installation
To get started with this project, clone the repository:
```bash
git clone https://github.com/abinaya-345/Heart-Disease-Classification-Using-Machine-Learning.git
```
Then navigate to the project directory:
```bash
cd Heart-Disease-Classification-Using-Machine-Learning
```

## 🚀 Usage
After installing the required dependencies, you can run the project using:
```bash
python main.py
```

## 📊 Dataset Information
The dataset contains various features that are used to train models for predicting heart disease. Each record includes attributes such as age, gender, cholesterol levels, and more.

## 🧠 Model Details
We use several models for classification, including:
- Logistic Regression
- Decision Trees
- Random Forest
- Support Vector Machines (SVM)

## 📈 Results
We evaluate model performance using metrics like accuracy, precision, recall, and F1 score. These metrics help us understand how well our models predict heart disease.
